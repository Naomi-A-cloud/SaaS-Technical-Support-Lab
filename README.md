# SaaS Technical Support Lab

## Overview

This project is a practical SaaS technical support simulation designed to demonstrate troubleshooting, ticket investigation, customer communication, technical documentation, prioritisation, escalation, incident management, and basic application and API troubleshooting.

The environment simulates a fictional SaaS platform called CloudDesk.

## Objectives

- Investigate customer support tickets
- Troubleshoot authentication and account-access issues
- Diagnose permissions and application errors
- Analyse simulated application and API logs
- Apply ticket prioritisation and SLA concepts
- Document troubleshooting procedures
- Create customer-facing support responses
- Identify when technical issues require escalation
- Document simulated incidents and root-cause analysis

## Technical Areas

- SaaS troubleshooting
- Application support
- Authentication
- MFA
- User permissions
- HTTP status codes
- API troubleshooting
- Log analysis
- Browser troubleshooting
- Incident management
- SLA management
- Root-cause analysis
- Technical documentation
- Git and GitHub

## Environment

Simulated SaaS Platform: CloudDesk

Support Role: Technical Support Engineer

Environment: Simulated production support environment

## Project Structure

- `docs/` - Troubleshooting guides and customer responses
- `tickets/` - Simulated customer support tickets
- `knowledge-base/` - Technical knowledge articles
- `support-process/` - Support workflows, SLA and prioritisation documentation
- `incidents/` - Simulated incident investigations
- `logs/` - Simulated application, authentication and API logs
- `evidence/` - Supporting screenshots and evidence

## Disclaimer

CloudDesk is a fictional SaaS platform created for portfolio and learning purposes. The tickets, incidents, logs and customer scenarios are simulated.
