# Ticket Prioritisation

## P1 - Critical

Major service outage or severe business impact.

Examples:

- Entire platform unavailable
- Authentication unavailable for all users
- Critical production failure

## P2 - High

Significant issue affecting one or more users with substantial business impact.

Examples:

- Important functionality unavailable
- Multiple users affected
- Significant application failure

## P3 - Medium

Limited impact with a workaround available.

Examples:

- Individual user issue
- Non-critical feature failure
- Browser-specific issue

## P4 - Low

Minor issue or general request.

Examples:

- Documentation request
- General question
- Cosmetic issue
