# Customer Communication Standard

## Objective

Technical Support communication should be clear, professional, accurate and easy for the customer to understand.

## Initial Response

The first response should:

- Acknowledge the issue
- Confirm understanding
- Request only necessary information
- Provide safe initial troubleshooting steps

## Investigation Update

An investigation update should explain:

- What has been checked
- What has been identified
- What happens next

## Escalation Update

When escalation is required:

- Explain that the issue has been escalated
- Avoid unnecessary technical jargon
- Explain the next action
- Maintain ownership of customer communication

## Resolution Message

A resolution message should include:

- What was resolved
- Any action the customer needs to take
- Confirmation that the issue is working
- Relevant prevention or troubleshooting advice

## Security

Never request or expose customer passwords, MFA codes, API secrets or authentication tokens.
