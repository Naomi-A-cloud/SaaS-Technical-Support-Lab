# Customer Response: MFA Issue

Hello,

Thank you for contacting CloudDesk Support.

If your MFA code is being rejected, please check that the date and time on your authentication device are set automatically.

Then generate a new authentication code and try again.

If the issue continues, please let us know the exact error message.

For security reasons, please do not send your MFA code to Support.
