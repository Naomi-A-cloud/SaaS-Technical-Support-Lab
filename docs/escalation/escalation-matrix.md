# Technical Support Escalation Matrix

| Issue | Priority | Initial Team | Escalation |
|---|---|---|---|
| Individual login failure | P3 | Technical Support | Engineering if unresolved |
| Multiple login failures | P2/P1 | Technical Support | Engineering / Incident Response |
| MFA failure | P2 | Technical Support | Engineering if service-related |
| Permission issue | P3/P2 | Technical Support | Administrator |
| HTTP 500 error | P2 | Technical Support | Engineering |
| HTTP 429 error | P2/P3 | Technical Support | Engineering |
| Major application outage | P1 | Technical Support | Incident Response / Engineering |
| Security-related event | P1/P2 | Technical Support | Security Team |
| Performance degradation | P3/P2 | Technical Support | Engineering |

## Escalation Information

Every escalation should include:

- Ticket ID
- Customer impact
- Priority
- Steps already performed
- Error messages
- Relevant timestamps
- Relevant logs
- Screenshots where appropriate
- Reproduction steps
- Current status
