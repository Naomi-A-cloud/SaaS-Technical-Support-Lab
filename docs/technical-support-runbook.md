# Technical Support Runbook

## Authentication Issue

1. Confirm affected user.
2. Verify account status.
3. Confirm credentials are not being shared.
4. Test authentication.
5. Check authentication logs.
6. Test browser/session behaviour.
7. Determine scope.
8. Resolve or escalate.

## Permission Issue

1. Confirm authenticated user.
2. Identify requested resource.
3. Check HTTP status.
4. Check user role.
5. Verify required permission.
6. Obtain appropriate approval.
7. Resolve or escalate.

## API Issue

1. Identify endpoint.
2. Identify HTTP method.
3. Record timestamp.
4. Identify status code.
5. Review API logs.
6. Check authentication.
7. Check rate limits.
8. Reproduce where possible.
9. Escalate if backend failure exists.

## Application Error

1. Reproduce the issue.
2. Record error message.
3. Record timestamp.
4. Review application logs.
5. Identify HTTP response.
6. Determine customer scope.
7. Escalate backend failures.

## Performance Issue

1. Confirm symptoms.
2. Reproduce issue.
3. Test browser behaviour.
4. Check response time.
5. Review API latency.
6. Review application logs.
7. Determine scope.
8. Escalate persistent degradation.
