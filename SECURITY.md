# Security

## Project Scope

CloudDesk SaaS is a fictional technical support environment created for portfolio and learning purposes.

No real customer information, credentials, API keys or production systems are used.

## Security Practices Demonstrated

- Authentication troubleshooting
- MFA troubleshooting
- Authorization and permissions
- API security concepts
- HTTP status codes
- Rate limiting
- Incident escalation
- Log investigation
- Secure handling of credentials
- Protection of sensitive information

## Sensitive Information

This repository must not contain:

- Passwords
- API keys
- Access tokens
- Private keys
- Customer credentials
- Production secrets
- Personally identifiable customer information

Environment variables and credential files are excluded through `.gitignore`.

## Incident Handling

Security-related issues should be:

1. Identified
2. Documented
3. Classified according to severity
4. Escalated when required
5. Investigated using available evidence
6. Resolved or handed over to the appropriate technical team

## Disclaimer

CloudDesk SaaS and all associated tickets, logs, customers and incidents are simulated for portfolio purposes.
